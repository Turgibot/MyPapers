  \block{}{%
    \asec{Abstract}
    {\bodytext
    Accurate Estimated Time of Arrival (ETA) prediction is essential for navigation, traffic management, and smart transportation. Dynamic Graph Neural Networks (GNNs) model evolving road networks, but research is hindered by limited datasets and the lack of a unified environment for data generation and model testing.

    We present an integrated open-source platform combining \textbf{Traffic-DSTG-Gen} (route-aware dynamic spatio-temporal graphs from SUMO simulation or GPS trajectories) and \textbf{TrafficLab} (interactive web-based ETA evaluation). The system supports 80{,}000+ simulation snapshots with 28-dimensional node and 7-dimensional edge features, and logs thousands of real-time test journeys with MAE/RMSE analysis.
    }

    \vspace{0.6em}
    \asec{Keywords}
    {\bodytext
    Graph Neural Networks; ETA Prediction; SUMO Simulation; Dataset Generation; Route-Aware Graphs; Testing Platform
    }

    \vspace{0.6em}
    \asec{II. Principle}
    {\bodytext
    ETA prediction requires data that links road topology, vehicle motion, and trip labels. Static-sensor and plain trajectory datasets often lack explicit routes and rich features for dynamic GNNs.

    \textbf{Principle:} one shared \emph{route-conditioned dynamic graph}, built via (1)~\textbf{simulation}---SUMO/TraCI with reproducible snapshots; or (2)~\textbf{trajectory conversion}---GPS traces map-matched to the same schema (e.g.\ Porto taxi). Both paths feed one training pipeline and one web evaluation client.
    }
  }

  \column{0.38}

  \block{}{%
    \asec{III. Theoretical Modelling}
    {\bodytext
    \textbf{Hybrid graph:} static junction nodes and road edges; dynamic vehicle nodes; time-varying junction--vehicle--vehicle--junction edges. \textbf{Features:} 28-D nodes, 7-D edges; sequential snapshots for temporal models.

    \textbf{Traffic-DSTG-Gen} (desktop, PySide6 + SUMO): scenario configuration, trajectory import, export. \textbf{TrafficLab} (Vue.js + FastAPI + PostgreSQL): route selection, ETA inference, journey persistence, cohort metrics.
    }
