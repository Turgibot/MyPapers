\begin{center}
{\large\bfseries Abstract}
\end{center}

\vspace{1em}

This project addresses a critical gap in traffic prediction research by developing a comprehensive multi-variant dataset generation framework that enables fair comparison across different model architectures for both flow forecasting and Estimated Time of Arrival (ETA) prediction. The system consists of two main components: (1) a SUMO-based multi-variant dataset generator that produces synchronized data formats tailored to different model types, and (2) a browser-based testing platform for real-time model evaluation and visualization.

The dataset generator creates four synchronized variants from a single underlying traffic simulation: a dynamic graph variant for dynamic GNN models, a trajectory variant for trajectory-based models, a static graph variant for sensor network models, and a route segment variant for route-aware models. This multi-variant approach ensures all models are evaluated on identical traffic patterns while receiving data in their native format, enabling rigorous comparison across architectural paradigms. The dataset supports both flow prediction (aggregate speed, volume, occupancy) and ETA prediction (individual vehicle travel times), making it a comprehensive resource for the research community.

The browser-based testing platform provides an interactive environment for real-time model evaluation, allowing researchers to visualize predictions, compare model performance, and analyze results through statistical dashboards. The system integrates SUMO traffic simulation with model inference, enabling testing of trained models on live traffic scenarios. This contribution provides the research community with a unified evaluation framework that bridges the gap between different modeling approaches and enables reproducible, fair comparisons across state-of-the-art methods.
