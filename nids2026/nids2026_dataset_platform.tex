\begin{abstract}
Accurate traffic prediction requires models that jointly capture infrastructure topology, vehicle dynamics, and route intent. However, existing traffic datasets typically represent road networks as static graphs or model vehicles independently, lacking a unified and route-aware spatio-temporal representation.

We present RAD-TG (Route Aware Dynamic Traffic Graph), a dynamic graph dataset for traffic modeling in which both junctions and vehicles are represented as nodes, and edges capture road connectivity together with evolving junction--vehicle--vehicle--junction relationships. Traffic is represented as a sequence of graph snapshots sampled at fixed temporal intervals, enabling explicit tracking of vehicle progress along predefined routes. This route-aware formulation reflects real-world navigation scenarios and supports prediction tasks that depend on destination intent.

RAD-TG provides a rich set of node and edge features designed for both vehicle-level predictions, such as ETA estimation, and region-level traffic analysis. To support reproducibility and adoption, we release an open-source generation framework that converts either a road network with trajectory data or a SUMO-based simulation with configurable behavior into the proposed graph representation. The resulting datasets unify synthetic and trajectory-based sources under a common route-aware dynamic graph format.

We validate RAD-TG using baseline spatio-temporal graph neural network models and demonstrate its suitability for a broad range of traffic prediction tasks. The proposed dataset and tooling establish a flexible foundation for research in route-aware forecasting, dynamic graph learning, and intelligent transportation systems.
\end{abstract}
